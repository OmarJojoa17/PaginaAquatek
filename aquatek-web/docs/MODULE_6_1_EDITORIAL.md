# Módulo 6.1 — Cierre editorial

## Objetivo

Cerrar el contenido de la primera versión pública antes de la auditoría técnica y el despliegue. El
sitio debe describir lo que Aquatek ofrece hoy, sin promesas vacías, datos provisionales ni canales
que todavía no funcionen.

## Revisión realizada

- La página de inicio habla en presente porque el primer proyecto ya está publicado.
- La página de empresa explica cómo se documentan los proyectos y cómo se protegen los originales.
- Las siete especialidades mantienen un lenguaje técnico comprensible.
- La ficha de la PTAP usa únicamente derivados web revisados.
- El pie de página ya no presenta el sitio como un portafolio en desarrollo.
- La vista previa continúa bloqueada para buscadores mientras no exista una URL pública aprobada.

## Decisiones pendientes del propietario

Antes del despliegue se deben confirmar:

1. Correo que aparecerá públicamente.
2. Número telefónico y si funcionará también como WhatsApp.
3. Ciudad base o cobertura geográfica que se puede comunicar.
4. Si la primera publicación en GitHub Pages seguirá con `noindex`.

No se deben copiar estos datos desde planos, memorias o documentos contractuales sin autorización
expresa.
